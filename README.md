# 轻填 · 志愿报名助手

静态网站 + Chrome/Edge Manifest V3 扩展。无第三方分析、无资料上传业务接口。

## 已实现

- 本机资料保存、任务管理、模板、备份导入导出、操作记录。
- 网站与浏览器扩展之间的限定来源通信。
- 按需授权具体 HTTPS 站点，打开真实表单并填充有明确标签的标准输入框。
- 定时预填、经试填验证后的定时单次点击提交；过期任务停止；不自动重试提交。
- 状态区分：预填、已点击待核实、需人工处理。没有伪造报名成功回执。
- 本站演示流程，使用与扩展相同的 DOM 字段匹配引擎。

## 边界

这是通用表单助手的首版。已通过用户提供的观影活动表观察到腾讯的 question-main-content、textarea 和 ARIA 年级单选结构，并实现对应适配。未登录状态下没有填入或提交任何资料；登录后的真实提交尚未验证。腾讯在线表格的 canvas 单元格不受本通用适配器支持。没有绕过验证码、登录或权限限制。复杂题型和文件上传留给用户处理。

浏览器 alarm 并非实时调度；电脑休眠、浏览器退出、页面加载与登录都会造成延误。不能保证毫秒级或抢到名额。距离计划执行时间超过 60 秒时不补交。

## 安装

网站使用指南包含 `quickfill-extension.zip` 下载。解压后在 Chrome/Edge 扩展管理页面通过“加载已解压的扩展程序”安装。扩展只连接本站的域名和 /qingfill/ 路径。首次执行目标平台任务，打开扩展确认页申请该域名的 host permission。

## 腾讯收集表 v1.1.1

新增年级、二级学院、专业独立资料；移除与实际表无关的手机号强制要求。检查模式只读取题目和选项，即使页面锁定也不改变控件，用于准备未来任务。到点执行仍要求已登录、表单开放且结构不变。已满、暂停、未开放、只读状态会停止。年级按完整标签匹配（包括专升本），学号始终按字符串保留，不擅自补零或去零。

适配依据为腾讯收集表的文本题和年级单选结构；不同活动的表单仍需单独检查。

## 验证

运行 `node scripts/check.mjs` 检查脚本语法和打包一致性；`node scripts/tencent-behavior.mjs` 验证腾讯结构适配的精确选项、状态停止与提交行为；`node scripts/behavior.mjs` 验证通用引擎及定时状态管理。浏览器 UI 验证网站资料持久化、任务管理、演示流程、筛选与导入。扩展未在用户浏览器安装，真实平台端到端验证需要用户提供原始表单并在本机完成安装。

## 源码

`docs/` 为部署目录。`extension/` 为完整扩展源码。`scripts/package.py` 复制共享引擎并生成扩展 ZIP。`scripts/check.mjs` 为源码校验。时间输入固定按 UTC+8 解释，显示为北京时间。
